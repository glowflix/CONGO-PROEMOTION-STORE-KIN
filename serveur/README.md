# 📊 Données Google Sheets - Congo Promotion Store

## 📋 Instructions d'importation

1. **Créez votre Google Sheets** nommé "CongoPromotionDB"
2. **Créez les onglets** suivants :
   - Products
   - Videos
   - AI_KB
   - Users
   - Comments
   - ProductLikes
   - Reviews
   - AI_Logs

3. **Importez les fichiers CSV** :
   - Ouvrez chaque onglet
   - Fichier > Importer > Télécharger
   - Sélectionnez le fichier CSV correspondant
   - Choisissez "Remplacer la feuille de calcul"
